# 🐍 Python Setup & Data Fundamentals Tutorial

This repository is a **step-by-step learning guide** for setting up Python in VS Code and understanding the fundamentals of data handling using:

* NumPy
* Pandas
* Matplotlib
* MySQL

It is designed as a **structured mini-course**, where each file builds on the previous one.
